# Рекомендательная система книг

Цель: реализовать, проанализировать и сравнить различные подходы рекомендательных систем для сервиса по подбору книг.

## Этапы работы

### Этап 1. Знакомство с данными и EDA (Exploratory Data Analysis)
Загружаются файлы: `ratings.csv`, `books.csv`, `tags.csv`, `book_tags.csv`.  
Проводится разведочный анализ:
- Анализ распределения оценок;
- Активность пользователей;
- Популярность книг: график «количество книг vs количество оценок»
- Выявление основных проблем данных: разреженность матрицы взаимодействий, смещение популярности и рейтингов.

### Этап 2. Базовые и контентные модели
Реализуются простые, но эффективные модели-бейзлайны:
- **Неперсонализированная модель**: Top‑N самых популярных книг по среднему рейтингу с порогом минимального количества оценок.
- **Контентная модель**: для каждой книги создаётся текстовый профиль из названия (`original_title`) и списка тегов. Профили векторизуются с помощью TF‑IDF. Реализована функция `get_similar_books(book_id, N=5)`: поиск N наиболее похожих книг по косинусной мере близости между их TF‑IDF‑векторами.

### Этап 3. Коллаборативная фильтрация (Collaborative Filtering — CF)
Классические методы CF и их ограничения:
- Строится матрица взаимодействий «пользователь — книга» (user_id × book_id). Значениями могут быть явные оценки или неявный feedback (например, 1 при оценке ≥ 4, иначе 0).
- **Item‑Based Collaborative Filtering**: рассчитывается матрица попарных схожестей между книгами (коэффициент корреляции Пирсона или косинусная близость по векторам оценок). Для заданной книги и пользователя оценка предсказывается усреднением оценок пользователя по K наиболее похожим книгам.
- Анализируется вычислительная сложность подхода и рассматриваются способы оптимизации для больших данных.

### Этап 4. Матричные разложения (Matrix Factorization)
Продвинутые и масштабируемые методы предсказания оценок:
- Используется библиотека `surprise` для обучения модели SVD.
- Данные разделяются на обучающую и тестовую выборки. Модель обучается, и ошибка предсказания оценивается по метрике RMSE на тесте.
- Реализована функция `get_recommendations(user_id, N=5)`, которая возвращает топ‑N книг с наибольшим предсказанным рейтингом для заданного пользователя.

### Этап 5. Оценка и сравнение моделей
Сравнение качества всех реализованных моделей по объективным метрикам:
- Для моделей, возвращающих топ‑N рекомендаций Popularity, Item‑Based CF, SVD, рассчитываются Precision@K, Recall@K и nDCG@K.

### Этап 6. Гибридизация и выводы
Сделаны предложение по улучшению.

## Стек технологий

- Python, pandas, numpy
- matplotlib, seaborn — для визуализации
- scikit‑learn — для TF‑IDF и косинусной близости
- surprise — для матричных разложений (SVD)
- Метрики: Precision@K, Recall@K, nDCG@K
